<h2><b><span style="color:#E91E63;">📊 Project Overview</span></b></h2>

This project analyzes an e-commerce database using SQL to understand customer behavior, product performance, sales trends, and business growth opportunities.

The objective is to transform raw transactional data into actionable business insights using SQL queries, aggregations, joins, and analytical techniques.

This project simulates a real-world business intelligence solution used in the retail and e-commerce industry for strategic decision-making.

---

<h2><b><span style="color:#6A1B9A;">🎯 Business Objective</span></b></h2>

This analysis answers key business questions such as:

* Which customers generate the highest revenue?
* Which products perform best in terms of sales?
* Which products are rarely purchased?
* What are the most preferred payment methods?
* How do daily sales trends impact business performance?
* Which products frequently go out of stock?

<h2><b><span style="color:#EF6C00;">🧠 SQL Concepts Used</span></b></h2>

<h3><b><span style="color:#3949AB;">🔹 Basic Queries</span></b></h3>

* Select customer and product data
* Filter data using WHERE
* Sort records using ORDER BY

---

<h3><b><span style="color:#3949AB;">🔹 Intermediate Queries</span></b></h3>

* Use DISTINCT, BETWEEN, LIKE
* Create calculated columns (price × quantity)
* Handle missing values using NULL

---

<h3><b><span style="color:#3949AB;">🔹 Aggregations</span></b></h3>

* COUNT() → Total Orders
* SUM() → Total Revenue
* AVG() → Average Order Value
* GROUP BY → Category & Customer Analysis

---

<h3><b><span style="color:#3949AB;">🔹 Joins</span></b></h3>

* INNER JOIN → Orders with Customers
* LEFT JOIN → Customers with/without Orders
* Combine Multiple Tables

---

<h3><b><span style="color:#3949AB;">🔹 Subqueries</span></b></h3>

* Products above average price
* Customers with/without orders
* Highest order per customer

---

<h3><b><span style="color:#3949AB;">🔹 Set Operations</span></b></h3>

* UNION → Combine Results
* INTERSECT → Common Data

---

<h2><b><span style="color:#C62828;">📈 Key Insights</span></b></h2>

* Few customers generate the majority of revenue.
* Some products are never sold.
* High-priced products have lower sales frequency.
* Certain products frequently go out of stock.
* Sales fluctuate based on order dates.
* Some payment methods are more preferred by customers.
